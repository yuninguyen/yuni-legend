# Spec-Kit Constitution

Use `.specify/memory/constitution.md` for stable Spec-Kit principles.

Rules:
- `AGENTS.md` remains higher-priority project policy.
- Do not weaken financial, security, RBAC, audit, migration, or secret-handling invariants without explicit user approval.
- Record durable principles, not temporary feature decisions.
- Keep version/date/rationale when making material governance changes.
- Check `CLAUDE.md`, `BUILD.md`, `PLAN-REVIEW.md`, templates, and skills for contradictions after a constitution change.
