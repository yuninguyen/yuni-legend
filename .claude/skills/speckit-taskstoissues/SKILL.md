# Spec-Kit Tasks to Issues

Convert `tasks.md` into self-contained issue descriptions.

Each issue should include scope, dependencies, acceptance criteria, verification, and relevant RebateOps invariants. Preserve task ordering and do not merge unrelated financial concerns.

Creating issues does not bypass `PLAN-REVIEW.md`, GitNexus impact analysis, or implementation authorization.
